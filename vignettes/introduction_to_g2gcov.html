Introduction to G2Gcov: Discrete-Time Duration Models with Time-Varying Covariates

Ka Lok Lee, Aaron Ramsey, and Noah Park

2026-11-02

Time-Varying Covariates in the G2G Model

The G2G model is a discrete-time duration model in which the individual-level per-period event probability is reparameterized as \(\theta = 1 - e^{-\lambda}\), with \(\lambda \sim \text{Gamma}(r, \alpha)\) across subjects. Time-varying covariates in period \(z(j)\) enter via a complementary log-log link,

\[ \theta_j = 1 - \exp\left(-\lambda e^{z(j)\beta'}\right), \]

which yields the closed-form survivor function

\[ S(t) = \left(\frac{\alpha}{\alpha + C(t)}\right)^r, \quad C(t) = \sum_{j=1}^{t} e^{z(j)\beta'}. \]

Required Data Format

Data must be in person-period (long) format:

  • One row per subject per time period.
  • A subject identifier column linking rows to the same individual.
  • An event indicator equaling 1 in the period the event occurred, and 0 in all other periods.

Support for Categorical and Non-Numeric Variables

The package natively handles non-numeric variables (both factor and character vectors) through standard R formula mechanics (via model.matrix):

  • Automatic Dummy Encoding: Multi-level factors are automatically expanded into binary dummy indicators using standard treatment contrasts (contr.treatment).
  • Baseline Hazard Interpretation: The first level is treated as the reference category and its effect is absorbed into the baseline frailty distribution parameterized by \(r\) and \(\alpha\).
  • Profile Predictions: When generating predictions with G2G_static_survival() or G2G_varying_survival(), passing a data.frame with the original factor levels ensures clean, automatic level mapping without needing manual dummy variable creation.

Example 1: Time-Varying Covariates (kb_data)

Note on Datasets: To ensure this vignette builds rapidly within CRAN limits, we evaluate the models using kb_data_sample, a 20-subject subset of the package’s full data intended for quick trials and interactive exploration. For full empirical analyses, simply use the entire cohort of 1,499 subjects via data(kb_data). The syntax remains identical.

Each row in the data represents one customer-week. We print the first 50 rows to illustrate the person-period structure required for time-varying modeling.

We estimate the model by directly supplying the formula and the subject identifier.

# Estimate the discrete-time model with dynamic marketing covariates
fit_varying <- G2G_varying_MLE(
  Surv(week, status) ~ coupon + anyp,
  data    = kb_data_sample,
  subject = "id"
)

# View the parameter estimates, standard errors, and Wald confidence intervals
print(fit_varying)

Estimation Details

Internally, the G2G_varying_MLE() function applies several techniques to ensure robust numerical optimization:

  • Automatic Standardization: To improve the numerical stability and convergence of the BFGS algorithm, all continuous covariates are automatically standardized (centered and scaled) prior to maximizing the likelihood. Upon convergence, the resulting coefficient estimates are dynamically rescaled back to their original metric, ensuring the output is immediately interpretable on the scale of the original data.
  • Delta Method for Standard Errors: The optimization routines estimate baseline parameters in an unconstrained space (e.g., using \(\log(r)\) and \(\log(\alpha)\) to enforce strict positivity constraints). The package computes the inverse Hessian matrix and applies the multivariate Delta method to derive the standard errors for the parameters on their original scale.
  • Wald Confidence Limits: Using these Delta method standard errors, the package automatically calculates and reports symmetric 95% Wald confidence intervals for all parameters, as shown in the print() output.
  • G2G_static_MLE() also uses these techniques to ensure robust numerical optimization

Visualizations

We can visualize the implied distribution of the baseline weekly event probability across the population.

plot_p0(fit_varying)

Next, we extract the survival curve explicitly using G2G_varying_survival() by passing a specific customer’s covariate path. We then plot the predicted step-function using base R graphics.

# Predict individual survival curve S(t) along a specific customer trajectory
# (Subject 24 is included in our sample)
customer_path <- kb_data_sample[kb_data_sample$id == 24, c("coupon", "anyp")]

# Compute the survival curve predictions explicitly
surv_est <- G2G_varying_survival(solution = fit_varying, X_mat = customer_path)

# Plot the predicted survival curve using base R graphics
plot(
  seq_along(surv_est), 
  surv_est, 
  type = "s",  # Step function for discrete time
  col  = "blue", 
  lwd  = 2,
  xlab = "Week", 
  ylab = "Survival Probability",
  main = "G2G Predicted Survival Curve (Subject 24)",
  ylim = c(0, 1)
)

Example 2: Static Covariate Baseline (veteran)

If covariates are fixed for each subject, the cumulative effect simplifies. The G2G_static_MLE() function handles data in traditional cross-sectional format (one row per subject) and automatically manages factor variables like celltype. We benchmark this using the veteran dataset.

vet <- survival::veteran
vet$id <- seq_len(nrow(vet))
fit_static <- G2G_static_MLE(
  Surv(time, status) ~ age + celltype,
  data = vet
)

# View the parameter estimates and model convergence for the static baseline
print(fit_static)

Just like the time-varying model, we can project survival for a specific subject profile (passing original factor levels) using G2G_static_survival().

# Predict survival up to t = 150 days for a 49-year-old with squamous cell cancer
surv_static <- G2G_static_survival(
  fit_static, 
  data.frame(age = 49, celltype = "squamous"), 
  150
)

plot(
  seq_along(surv_static),
  surv_static,
  type = "s",
  col  = "red",
  lwd  = 2,
  xlab = "Days",
  ylab = "Survival Probability",
  main = "G2G Predicted Survival Curve (Static Profile)",
  ylim = c(0, 1)
)
