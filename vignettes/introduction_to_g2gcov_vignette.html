Introduction to G2Gcov: Discrete-Time Duration Models with Time-Varying Covariates

Ka Lok Lee, Aaron Ramsey, and Noah Park

2026-11-03

Package Overview

G2Gcov implements maximum likelihood estimation, diagnostic baseline plotting, and survival/retention trajectory forecasting for discrete-time duration data with time-varying covariates and unobserved cross-sectional heterogeneity:

Function Purpose
G2G_varying_MLE() Maximum likelihood estimation with time-varying covariates
G2G_static_MLE() Maximum likelihood estimation with time-invariant covariates
print() S3 print method displaying estimates, SEs, Wald confidence intervals, and AIC
plot_p0() Plot baseline per-period event probability density \(p_0\) across the cohort
G2G_varying_survival() Compute discrete-time survival function \(S(t)\) along dynamic covariate paths
G2G_varying_retention() Compute period-to-period retention function \(r(t)\) along dynamic covariate paths
G2G_static_survival() Compute discrete-time survival function \(S(t)\) under static covariates
G2G_static_retention() Compute period-to-period retention function \(r(t)\) under static covariates

Time-Varying Covariates in the G2G Model

The G2G model is a discrete-time duration model in which the individual-level per-period event probability is reparameterized as \(p_0 = 1 - e^{-\lambda}\), with \(\lambda \sim \text{Gamma}(r, \alpha)\) across subjects. Time-varying covariates in period \(j\), \(z(j)\), enter via a complementary log-log link with coefficients \(\beta'\),

\[ p_j = 1 - \exp\left(-\lambda e^{z(j)\beta'}\right), \]

which yields the closed-form survivor function

\[ S(t) = \left(\frac{\alpha}{\alpha + C(t)}\right)^r, \quad C(t) = \sum_{j=1}^{t} e^{z(j)\beta'}. \]

Required Format for Time-Varying Covariates Data

Data must be in person-period (long) format:

  • One row per subject per time period.
  • A subject identifier column linking rows to the same individual.
  • An event indicator equaling 1 in the period the event occurred, and 0 in all preceding periods.
Column Type Description
id Identifier Unique subject identifier (numeric, character, or factor)
week (or time) Integer Sequential discrete period index (\(1, 2, 3, \dots\))
status Binary (0/1) 1 if the event occurred in that specific period; 0 in the preceding periods; all 0s through the last observed period for censored subjects
coupon, anyp, ... Numeric / Factor Dynamic or static covariates (continuous, binary, or multi-level)

The package natively handles numeric and non-numeric variables (both factor and character vectors) through standard R formula mechanics (model.matrix):

  • Automatic Dummy Encoding: Multi-level factors are automatically expanded into binary dummy indicators using standard treatment contrasts (contr.treatment).
  • Coefficient Interpretation: The first level of each factor is the reference category, and its dummy variables equal zero. For character vectors, R orders levels alphabetically, so the first level is the alphabetically first value; use factor(x, levels = ...) or relevel() to choose a different reference. The baseline per-period event probability, \(p_0 = 1 - e^{-\lambda}\) with \(\lambda \sim \text{Gamma}(r, \alpha)\), describes subjects at the reference levels (and zero for numeric covariates). Each coefficient \(\beta_k\) acts on the complementary log-log scale, so \(e^{\beta_k}\) is a hazard ratio: a one-unit increase in a numeric covariate, or a switch from the reference level to a given factor level, multiplies \(\lambda\) by \(e^{\beta_k}\). A positive \(\beta_k\) raises the per-period event probability (shorter durations); a negative \(\beta_k\) lowers it (longer durations).
  • Profile Predictions: When generating predictions with G2G_static_survival() and G2G_varying_survival(), passing a data.frame with the original factor levels (e.g., data.frame(age = 49, celltype = "squamous")) ensures clean, automatic level mapping.

Example 1: Time-Varying Covariates (kb_data)

Note on Datasets: To ensure this vignette builds rapidly within CRAN limits, we evaluate the models using kb_data_sample, a 20-subject subset of the package’s full data intended for quick trials and interactive exploration. For full empirical analyses, simply use the entire cohort of 1,499 subjects via kb_data<-G2Gcov::kb_data. The syntax remains identical.

We estimate the model by directly supplying the formula and the subject identifier.

# Estimate the discrete-time model with dynamic marketing covariates
fit_varying <- G2G_varying_MLE(
  Surv(week, status) ~ coupon + anyp,
  data    = kb_data_sample,
  subject = "id"
)

# View parameter estimates, standard errors, and Wald confidence intervals
print(fit_varying)

Estimation Details

Internally, G2G_varying_MLE() applies several techniques to ensure robust numerical optimization:

  • Automatic Standardization: To improve numerical stability and convergence of the BFGS algorithm, all continuous covariates are automatically standardized (centered and scaled) prior to maximizing the likelihood. Upon convergence, the resulting coefficient estimates are dynamically rescaled back to their original metric, ensuring the output is immediately interpretable on the scale of the original data.
  • Delta Method for Standard Errors: The optimization routines estimate baseline parameters in an unconstrained space (e.g., using \(\log(r)\) and \(\log(\alpha)\) to enforce strict positivity constraints). The package computes the inverse Hessian matrix and applies the multivariate Delta method to derive standard errors on their original scale.
  • Wald Confidence Limits: Using Delta method standard errors, the package automatically calculates and reports symmetric Wald confidence intervals for all parameters. By default, it reports 95% confidence limits, which can be modified via the level argument (e.g., level = 0.99).
  • G2G_static_MLE() applies these same optimization and standardization techniques.

Visualizations and Projections

We can visualize the implied distribution of the baseline weekly event probability across the population:

plot_p0(fit_varying)

Next, we extract the survival curve explicitly using G2G_varying_survival() by passing a specific customer’s covariate path, and plot the predicted step-function. The length of the generated survival curve aligns with the length of the covariate path provided:

# Predict individual survival curve S(t) along a specific customer trajectory
# (Subject 24 is included in our sample)
customer_path <- kb_data_sample[kb_data_sample$id == 24, c("coupon", "anyp")]

# Compute the survival curve predictions explicitly
surv_est <- G2G_varying_survival(solution = fit_varying, X_mat = customer_path)

# Plot the predicted survival curve using base R graphics
plot(
  seq_along(surv_est), 
  surv_est, 
  type = "s",  # Step function for discrete time
  col  = "blue", 
  lwd  = 2,
  xlab = "Week", 
  ylab = "Survival Probability",
  main = "G2G Predicted Survival Curve (Subject 24)",
  ylim = c(0, 1)
)

We can also project conditional period-to-period retention function along that same dynamic customer path using G2G_varying_retention():

# Compute period-to-period retention r(t) = P(T > t | T > t - 1)
ret_est <- G2G_varying_retention(solution = fit_varying, X_mat = customer_path)

# Display 
head(data.frame(Week = seq_along(ret_est), Retention = round(ret_est, 4)))
#>   Week Retention
#> 1    1    1.0000
#> 2    2    0.9961
#> 3    3    0.9964
#> 4    4    0.9947
#> 5    5    0.9640

Example 2: Static Covariate Baseline (veteran)

If covariates are fixed for each subject, the cumulative hazard simplifies. G2G_static_MLE() handles data in traditional cross-sectional format (one row per subject) and automatically manages factor variables like celltype. We demonstrate this using the veteran dataset.

vet <- survival::veteran
vet$id <- seq_len(nrow(vet))
fit_static <- G2G_static_MLE(
  Surv(time, status) ~ age + celltype,
  data  = vet,
  level = 0.99
)

# View parameter estimates and model convergence for the static baseline
print(fit_static)

plot_p0(fit_static)

Just like the time-varying model, we can project survival and period retention for a specific profile (passing original factor levels) using G2G_static_survival() and G2G_static_retention(). In this situation, we can also specify the length of these functions to be generated:

# Predict survival up to t = 150 days for a 49-year-old with squamous cell cancer
surv_static <- G2G_static_survival(
  fit_static, 
  data.frame(age = 49, celltype = "squamous"), 
  150
)

plot(
  seq_along(surv_static),
  surv_static,
  type = "s",
  col  = "red",
  lwd  = 2,
  xlab = "Days",
  ylab = "Survival Probability",
  main = "G2G Predicted Survival Curve (Static Profile)",
  ylim = c(0, 1)
)

# Predict period-to-period retention across the first 10 days
ret_static <- G2G_static_retention(
  fit_static, 
  data.frame(age = 49, celltype = "squamous"), 
  10
)
